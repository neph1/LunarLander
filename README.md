
A birthday project for my son, based on one seen in an exhibition. It's far from perfect and is not claiming to be physically realistic.


https://github.com/user-attachments/assets/807f2724-2324-4a5d-9fd0-29d5514f34f8

Instruments read (from left to right):

Orientation (middle is upright)

Lateral velocity (middle is zero).

Vertical velocity

Altitude (meters!)

Fuel


Green on the instruments is considered to be safe for landing (but the ground might still be too steep, no indication of that).

Supports controllers (only tested with X360). No key assignment. Left stick looks around, right stick controls orientation.

Can also be played with WASD + space for thrust. (easier).
